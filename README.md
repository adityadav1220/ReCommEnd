# 🎬 ReCommEnd

**ReCommEnd** is a hybrid recommendation engine that intelligently blends content-based and collaborative filtering to suggest personalized **movies**, **anime**, **K-Dramas**, and **TV shows**.

It’s built to scale across multiple media types using a modular design — giving users smarter and more relevant content recommendations.

---

## 📌 Features

- ✅ **Content-Based Filtering** using genre similarity
- ✅ **Collaborative Filtering** via matrix factorization (SVD)
- ✅ **Hybrid Model** combining both for improved accuracy
- ✅ **Intelligent Input Matching** (suggests titles when user input is partial)
- ✅ 📺 Works for multiple domains: Movies, Anime, TV shows, K-Dramas
- ✅ CLI-based interaction with clean outputs and prompts
